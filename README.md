# Flair landing page

Static marketing site (plain HTML/CSS/JS, no build step). All copy, numbers and product names are placeholders - edit `index.html`. Design tokens (colors, fonts, radius) are at the top of `styles.css`.

Run locally: open `index.html`, or `npx serve .`

Deploy: import this repo on Vercel (framework preset: Other, no build command, output directory `.`).
